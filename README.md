# 黑名单系统 Pro

一个区分「拉黑」和「屏蔽」的 AstrBot 黑名单插件。

- **拉黑**：拦截目标用户的所有消息，包括普通聊天和指令。
- **屏蔽**：只阻止目标用户唤醒 LLM，不影响其使用其他插件指令，也不影响其他人在唤醒 LLM 时让模型看到该用户的消息。
- 支持按群、私聊、全局三个范围记录；支持临时时长和永久。
- 支持智能指令：用自然语言描述对象、原因和时长，由模型解析后执行。
- 提供 LLM 工具 `add_to_blacklist` / `remove_from_blacklist`，可让模型在对话中主动拉黑/屏蔽用户，并解除自己添加的记录。

## 指令

以下指令均需要管理员权限（`拉黑`/`屏蔽`/`解除拉黑`/`解除屏蔽` 之外的查看类指令按配置放开，`查看全部黑名单` 除外，它仅管理员可用）。

### 拉黑 / 屏蔽

```text
/拉黑 @某人
/拉黑 -u 123456 -t 1d2h
/拉黑 -q 全局 -u 123456 -t 30min
/屏蔽 @某人 -t 20min
```

- 可以艾特、引用消息，或使用参数。
- 参数：`-q` 群号（`all`/`全局` 表示全局，不填表示私聊），`-u` 用户ID，`-t` 时长。
- 时长格式：`1d2h3min4s`，支持 `day/d`、`h`、`min/m`、`s`；纯数字视为分钟。
- 不写 `-t` 时默认永久。

### 解除拉黑 / 解除屏蔽

```text
/解除拉黑 @某人
/解除屏蔽 -q 全局 -u 123456
```

### 查看

```text
/查看黑名单
/查看黑名单 @某人
/查看黑名单 -q 全局 -u 123456
/查看群黑名单
/查看群黑名单 123456
/查看全部黑名单
```

- 普通用户默认只能查询自己；可在配置中放开。
- `查看群黑名单` 对普通用户默认关闭。
- `查看全部黑名单` 仅管理员可用，一次列出所有群、私聊和全局的记录，按「全局 → 私聊 → 群」分组，自动跳过已过期的记录，并显示每条记录的操作者。

### 搜索 / 清空

```text
/搜索黑名单 123456
/搜索黑名单 张三 m
/搜索黑名单 张三 a
/清空黑名单
/清空黑名单 123456 -y
/清空黑名单 全局 -y
```

搜索模式：`i` 按用户ID（默认），`m` 按用户名模糊匹配，`a` 同时匹配用户名和用户ID。

### 智能指令

```text
/智能拉黑 @某人 刷屏，关10分钟
/智能拉黑 -u 123456 发广告 1d
/智能拉黑 张三 一直捣乱 永久
/智能屏蔽 @某人 插话 20min
/智能解除拉黑 @某人
/智能解除屏蔽 -u 123456
```

- 模型会从自然语言中解析用户、群号、理由和时长；解析失败时回退到普通参数解析。
- 支持艾特/引用、QQ号、本群昵称（昵称匹配到多人时会列出候选）。
- 智能指令未给出时长时默认 20 分钟；明确说「永久」则不过期。
- 使用配置项「模型」指定的对话模型；留空时使用当前会话的默认模型。

### 屏蔽群聊

```text
/屏蔽该群
/拉黑该群
/屏蔽该群 123456
/解除屏蔽该群
/解除拉黑该群
```

被屏蔽的群所有消息都会被拦截（不区分屏蔽/拉黑）。

## 配置

| 配置项 | 说明 |
| --- | --- |
| 黑名单群聊 | 整个群的消息都拦截 |
| 包括管理员 | 拉黑/屏蔽对管理员是否生效 |
| 用户可查 | 普通用户能否查询自己是否被拉黑/屏蔽 |
| 用户可查群 | 普通用户能否查看本群的黑名单 |
| llm工具模式 | LLM 工具允许使用的模式，全不选则禁用这两个 LLM 工具 |
| 模型 | 智能指令使用的模型，留空使用当前会话默认模型 |

## LLM 工具

插件注册了 `add_to_blacklist`，模型可在对话中调用：

- `user_id`：用户ID
- `time`：时长（默认 20min）
- `reason`：理由
- `mode`：`屏蔽` 或 `拉黑`

管理员手动设置的记录不会被 `add_to_blacklist` 覆盖。

以及 `remove_from_blacklist`，用于解除拉黑/屏蔽：

- `user_id`：用户ID

`remove_from_blacklist` 只能解除模型自己（操作者为 `llm`）添加的记录，管理员手动设置的记录必须由管理员用解除指令处理；在当前群找不到记录时会再去查全局记录。配置项「llm工具模式」全不选时两个工具都会禁用。

## 数据

数据保存在 AstrBot 的插件数据目录（`data/plugin_data/黑名单系统/data.json`），
按 `群ID -> 用户ID -> 记录` 的结构存储，写入时使用临时文件替换，避免半截文件。
过期的记录由后台任务定期清理，插件卸载时也会清理一次。

## 注意事项

- 「全局」记录对所有群和私聊生效；「私聊」记录只对私聊生效。
- 拉黑发生在消息处理的最前面，被拉黑用户无法触发任何指令；屏蔽只作用于 LLM 请求阶段。
- 管理员是否受影响由「包括管理员」控制；管理员执行本插件指令时始终放行。
